== Sociální struktura třídy a vybraní žáci

// Proč se vztahová síť nezměnila, i když se zlepšilo vnímání klimatu: jednorázová intervence, změna

== Chování žáků ve hře a reflexe

== Srovnání s obdobnými výzkumy

// innemanova2009ovlivneni (5. roč., hry, SO-RA-D před/po – také bez výrazné změny struktury);
// Way (Schrier & Shaenfield 2016); Classcraft (Sanchez et al. 2016).

== Limity výzkumu

// Jedna třída, bez kontrolní skupiny; dlouhá prodleva pre-test → intervence a krátká intervence → post-test;
// změna složení třídy; nepřítomní žáci (pre-test 22/25); atmosféra jen za třídu, hodnoty z grafu;
// neznámé psychometrické vlastnosti nástroje; dvojí role autorky; reaktivita a efekt novosti;
// zdroje: gundry2019validity, hamari2014does (s. 3029), Shadish, Cook & Campbell 2002 (dohledat).
