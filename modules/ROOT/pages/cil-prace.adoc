== Výzkumné otázky

// Ze schváleného designu výzkumu (05/2025):
// VO1: Zlepšila se atmosféra ve třídě po absolvování digitální hry?
// VO2: Jaký dopad má digitální hra na žáky s nízkým sociometrickým statusem?
// VO3: Nastaly změny mezi žáky, kteří mají největší pozitivní nebo negativní vliv na kolektiv třídy?
// !!! Před finálním zněním rozhodnout s vedoucím: definice "nízkého statusu" a "největšího vlivu"
// (v datech se překrývají – viz podklady/analyza/navrh-analyzy-vysledky.md, kap. 4).
// Zvážit, zda VO1 formulovat popisně ("Jak se změnilo hodnocení atmosféry…"), protože atmosféra
// je k dispozici jen za celou třídu.
